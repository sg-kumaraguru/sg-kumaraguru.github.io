### 🚀 Featured Projects

#### [WriteMesh](https://github.com/sg-kumaraguru/WriteMesh) - Multi-User Blog Platform
A full-stack MERN application with authentication, role-based access control, and content management. Built to support collaborative writing with a clean, modern interface.

- **Stack**: `MongoDB` `Express` `React` `Node.js` `JavaScript` `CSS`
- **Key Features**: User authentication, role-based permissions, CRUD operations for posts

#### [MailWise](https://github.com/sg-kumaraguru/MailWise) - AI-Powered Email Automation
An intelligent email platform that integrates **RAG** and **FAISS** for semantic search, spam detection, and automatic task extraction. Synchronizes with Gmail in real-time, using PostgreSQL for robust data storage.

- **Stack**: `Python` `JavaScript` `PostgreSQL` `RAG` `FAISS` `Gmail API`
- **Key Features**: Semantic email search with chatbot, AI-driven spam filtering, task extraction, real-time Gmail sync
